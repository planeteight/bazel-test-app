# PulseBoard Android App

This app is the PulseBoard frontend for mobile. It presents analytics and planning outputs from backend services:

- `cpp-momentum-service` for weekly momentum and risk analytics.
- `java-focus-planner` for focus-session planning recommendations.

## Run in Android Studio

1. Open `android-pulseboard` in Android Studio.
2. Let Gradle sync complete.
3. Run on an emulator or connected Android device.

## Notes

- If your environment does not have Gradle configured globally, Android Studio can still sync this project with its embedded tooling.
- This project intentionally keeps one simple screen for demo reliability.
